# 잔문 殘文 / JANMUN

독립 문학 편집실 · 문학의 바깥을 읽는다.

## 현재 버전
v1.2.0 — 창립 준비용 정적 웹사이트. 모집, 실제 원고 접수, 판매는 시작하지 않았습니다.

## 파일 구성
- `index.html`: 홈, 창립 문서 4편, 총서, 투고, 아카이브, 소식, 나의 서재
- `css/style.css`: 디자인 토큰, 공통 편집 레이아웃, 반응형 및 인쇄 스타일
- `js/main.js`: 페이지 전환, 검색, 아카이브, 독서 기록, Q&A 및 초안 다운로드
- `js/news-data.js`: 공개 공지 데이터 (고유 ID, 분류, 제목, 상태, 게시일, 수정일, 고정, 본문, 링크)
- `assets/`: 로고 및 편집 그래픽
- `.nojekyll`: GitHub Pages 정적 배포

## 로컬 실행 및 배포
VS Code에서 프로젝트 폴더를 열고 `git pull` 후 `index.html`을 브라우저에서 열거나 Live Server로 확인합니다.
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
주소: https://janmun-editorial.github.io/

## 공지 수정
`js/news-data.js`의 배열에 공지를 추가합니다. ID는 중복하지 않고 date는 YYYY-MM-DD, 수정하지 않은 updated는 null로 둡니다. 공지 URL은 /news/ID/입니다. 실제로 확정하지 않은 일정은 명시적으로 준비 중 또는 기획 중으로 표기합니다.

## 배포 전 확인
- 홈과 9개 내부 화면 전환, 브라우저 뒤로/앞으로, 직접 공지 링크
- 아카이브/소식/투고 Q&A 분류·검색, 나의 서재 저장/삭제/내보내기
- 다크 모드, 좁은 모바일 화면, 키보드 탐색, 인쇄 화면
- CSS/JS 수정 후 index.html의 해당 파일 버전 쿼리 갱신

## 실제 운영 전
운영자·연락처, 모집 일정·심사 기준, 개인정보 처리 및 원고 보관 절차, 비공개 접수 경로를 확정해야 합니다. 원고나 개인정보를 공개 저장소에 넣지 않습니다. 투고 준비 노트는 로컬 TXT 생성 기능이며, 기록은 브라우저에만 저장됩니다. 사용자별 계정이나 기기 간 동기화는 없습니다.

## 검색용 정적 페이지
- index.html은 홈페이지이자 공통 원본입니다. 다른 화면은 template 요소로 보관됩니다.
- 원본 또는 공지 수정 후 Node.js가 있는 환경에서 `node scripts/build-pages.mjs`를 실행하면 정적 페이지와 sitemap.xml을 재생성합니다. 서버나 유료 서비스는 필요하지 않습니다.
- 기존 해시 주소는 새 URL로 연결됩니다. 나의 서재는 noindex 및 사이트맵 제외입니다.
- 호스트 루트의 robots.txt에서 새 사이트맵을 안내합니다. 검색엔진 소유권 인증은 새 주소 기준으로 별도 진행합니다.
- 검색엔진 인증용 meta 태그는 SEO BEGIN/END 밖 head에 두면 재생성 시 유지됩니다.
